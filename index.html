Reading the Results

Skill is the RMSE reduction versus smart persistence (tomorrow equals today).
nRMSE divides RMSE by plant peak, so results compare across plants.
Daylight R² excludes night hours, where zero output would inflate the score.
Coverage close to the target means the uncertainty is honest: neither overconfident nor uselessly wide.

Statistical Significance

Diebold–Mariano test on daily squared error over held-out days. A positive difference means the model has lower error than the baseline; p < 0.05 is treated as significant.

Methodology

How accuracy is measured

Models are fitted on the first 80% of the series only. Forecasts are issued at 23:00 and cover the next 24 hours, for every day in the final 20%. Alternate days calibrate the stacking weights and prediction intervals; the remaining days are never seen during fitting and produce every figure above.

Pipeline Flow

Five stages from raw data to a calibrated forecast

1. Load & validate CSV
2. Impute + cap outliers (IQR)
3. Engineer cyclical + lag features
4. Fit GBM / SARIMA-style / kernel models
5. Stacked ensemble + calibrated intervals

Limitations & Future Work

Known constraints and planned improvements

• The six trained models (Forecast page) learn from past power only. The Live Weather page adds numerical weather prediction input from Open-Meteo for the next 7 days. Power in the dataset is modelled from measured and reanalysis weather for a 12 kWp reference plant; it is not metered.
• The models are lightweight JavaScript re-implementations. A production system would use scikit-learn, XGBoost or LSTM behind the API listed below.
• Next steps: additional NWP feeds (Open-Meteo, ECMWF), satellite cloud-motion tracking, quantile regression forests, online learning and multi-site transfer.
